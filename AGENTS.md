# Development instructions

This is the new event-built ReverseSteps visual-memory module. The old Android app and October 25 preparation preview are outside this repository and must not be copied in.

- Read README.md, PROVENANCE.md and docs/BUILD_PLAN.md first.
- Keep capabilities and dates truthful. Never simulate or label fixture output as a model result.
- Runtime AI integrations use Meta models; development coding tools may differ.
- No credentials, personal photographs, signing keys, local environment files or private run logs in Git. No API calls unless account/credit readiness and an appropriate input are established.
- Source evidence must retain session, step, image and observation identities. Validate model output and surface uncertainty. A valid reference does not prove a correct match.
- Keep the first milestone focused on one object and the evidence-backed part-match workflow.
- Run `py -m unittest discover -s tests -v` and `py -m reversesteps validate examples/recorded-session.json` after changing evidence behavior. Add meaningful cases for changed behavior.
- Codex coordinates integration. Claude may work on an explicitly assigned scope; agree on shared interfaces before editing overlapping files. Record actual contributions in PROVENANCE.md.
- Do not publish demos, incur paid usage, alter account billing or submit the entry without the user's authorization for that action.
